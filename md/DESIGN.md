# Hydro — UI/UX Design Specification

## Design Goal
Dashboard harus interaktif, real-time, up-to-date, responsif, dan mudah digunakan pada desktop maupun HP.

## Pages
### Login/Register
Form autentikasi dengan validasi.

### Dashboard
- Kartu status sensor.
- Grafik real-time.
- Kontrol relay.
- Tabel historis.

### Device Management
Tambah/edit perangkat untuk admin.

### Settings
Profil dan ubah password.

## Responsive
- Mobile-first dengan Tailwind CSS.
- Sidebar collapsible pada mobile.
- Grafik adaptif untuk layar kecil.

## UX States
Sediakan state yang sesuai untuk loading, empty data, error, connected, dan disconnected/offline.

## Naming
Nama sensor, actuator, field, dan status harus konsisten dengan firmware, MQTT, backend, dan database.
